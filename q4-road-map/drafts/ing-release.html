Initiative 1 · Release and promotion

One release, three gates, every client

SAME IMAGE EVERYWHERE

Built once and promoted by digest. Clients differ only in env vars and pipeline configs in Git.

ONE MR PER STEP

A fleet repo pins each client's staging, QA and prod version; each client's Jenkins deploys it.

SAFE TO ROLL BACK

Smoke test after every deploy; a failure puts the previous version back. Schema changes in two steps.

Data Platform Roadmap · 10f

This is how a change reaches the clients, now that each client runs its own copy of the ingestion platform in its own environment. Everything we ship, the UI, the API, the scheduler, the alerts, the workers and the dlt wrapper, is one versioned release. A fix starts as a pull request with review and tests. A version tag builds two images, the backend and the UI, once; they are scanned and signed and stored in GitHub Container Registry. From then on the same image moves through every environment and is never rebuilt. Every client has three environments: staging, QA and prod. A release goes to staging for every client first: deploy, run the database migration, and a smoke test. It moves on only when every client is green; a problem in one client's environment, like an expired credential, can be waived with written sign-off, but a platform bug stops the release and we fix it with a patch. Then QA for every client: regression runs and reconciliation, and sign-off. Only then does it go to prod, and every client runs the same prod version. We can still start prod with a pilot wave of two or three clients, a night ahead of the rest. Which client runs which version is written in one fleet repository, so each step is one merge request, and each client's own Jenkins does the deploy. If the smoke test fails after a deploy, Jenkins puts the previous version back automatically; database changes are made in two steps so that is always safe. PII registries and role scripts are one-time setup per client and are not part of this release. In Q4 this is ING-04, ING-27 and ING-28, about 88 hours, all with Vatsal, and ADR-14 records the rules.
